# Facebook Hype Ads

## Purpose

Use this file as the common visual and layout standard for the individual Tour of Hell Facebook hype ads.

Each room/area should have its own scene-specific prompt based on the current script and room notes, but every ad should follow the shared rules below unless a deliberate exception is made.

## Format

- **Platform:** Facebook post
- **Aspect ratio:** vertical **4:5**
- **Target size:** **1080 × 1350**
- Build the composition for easy reading on a phone.

## Shared composition

### Upper third — headline

- Reserve the upper third for a short, strong **question, statement, or Bible verse** tied directly to that room.
- Use **large, bold, condensed white text**.
- Keep the background behind the text dark and relatively uncluttered.
- The headline should be the first thing seen while scrolling.
- Keep it serious and readable rather than using exaggerated horror typography.

### Middle — room concept

- Use the middle of the image for the main visual concept of the room.
- Base the scene on the **current room script and current implementation notes**.
- Take artistic liberties when needed to communicate the idea, but keep the depicted scale reasonably consistent with a church-produced theatrical walk-through.
- Do **not** oversell a room by turning it into an enormous fantasy environment that the live event cannot support.
- Favor one clear visual idea over a crowded collection of unrelated details.

### Lower third — website

- Allow the image to darken toward the bottom.
- Center the website prominently in clean, bold white text:

  **TOUROFHELL.CC**

- It should be easy to read on a phone, but smaller than the upper headline.

## Visual style

Use a **hand-drawn cinematic concept-art** style rather than photorealism.

The preferred look is:

- illustrated theatrical key art
- polished production-concept sketch
- visible linework
- sketch-like texture
- painterly shading
- hand-rendered feel
- stylized cinematic lighting
- atmospheric environment illustration
- strong silhouettes and readable composition
- polished enough for advertising while still visibly illustrated

The finished image should feel like a **hand-drawn production concept painting**, not a photograph.

## Tone

- Spiritually serious
- Biblical
- Ominous when appropriate
- Dramatic without becoming fantasy spectacle
- Designed to create curiosity and anticipation
- Avoid generic haunted-house imagery when it does not belong to the room
- Avoid gore as a primary advertising device
- Avoid making Hell look like an elaborate fantasy kingdom or Satan's fortress unless a specific room intentionally calls for that imagery
- Preserve the distinction between theatrical symbolism and claims about the literal appearance of the afterlife

## Color and lighting

Color should follow the individual room, but in general:

- favor strong dark values and controlled highlights
- use lighting to guide attention toward the room's main idea
- keep enough negative space for the upper headline and lower website
- use smoke, mist, haze, glow, shadow, or other atmosphere only where they support the actual room concept
- keep the image readable at Facebook/mobile size

## Prompt construction

For each new ad:

1. Read the current script and room-specific notes first.
2. Identify the room's single strongest visual idea.
3. Choose a short headline, question, statement, or Bible verse that matches the room's message.
4. Describe the actual scene elements that should appear.
5. Explicitly state what should **not** appear when common image-generation tropes would misrepresent the room.
6. Apply the shared upper-third / middle / lower-third composition.
7. Apply the hand-drawn cinematic concept-art style.
8. Keep the result visually dramatic without implying a larger or more elaborate live production than the room actually provides.

## Consistency goal

The complete series should look like one coordinated advertising campaign even though every room has a different subject.

Consistency comes from:

- the 4:5 format
- headline placement
- website placement
- hand-drawn concept-art treatment
- serious biblical tone
- restrained theatrical scale
- strong dark composition with scene-specific lighting and color


## Prompt output convention

- When presenting a finished Tour of Hell Facebook hype-ad image prompt to the user, place the full prompt inside a **copyable fenced code block**.
- Keep shared campaign rules in this file rather than repeating them in every room prompt. Room-specific prompt files should reference this file and contain only the details that differ for that scene.

## Facebook post copy

Each hype image should have matching Facebook post copy built around the same room-specific message.

### Standard structure

1. Start with:
   **🔥 TOUR OF HELL 2026 🔥**
2. Follow with the image's upper-third question, statement, or verse as the hook.
3. Add a short room-specific paragraph explaining the biblical idea behind the image without giving away the entire scene.
4. Keep the wording natural, direct, and easy to read on a phone.
5. Follow with the standard event-information block.
6. End with the age/intensity notice and campaign hashtags.

### Standard event-information block

Use this unless current project context changes:

📅 Sundays: October 4, October 18 and October 25  
🕒 3:00–8:00 PM  
📍 Main Street Church of God  
66 Main St, Russell Springs, KY 42642

Tours begin every 12 minutes. Advance registration is recommended. Walk-ins are first come, first served after preregistered guests.

Register today: **https://tourofhell.cc**

Please be aware that this experience is designed for middle-school-aged youth and older. Due to its intense content and effects, younger children should not attend.

#TourOfHell #RussellSprings #MainStreetChurchOfGod

### Copy tone

- Tie the opening paragraph directly to the room's script and biblical theme.
- Create curiosity without summarizing the whole room.
- Give only a glimpse of the room's theme. Do not reveal specific scene actions, character blocking, dialogue beats, surprises, or other details that would spoil the live experience.
- Keep the spiritual point serious and clear.
- Do not sensationalize, use gore-heavy language, or imply that the theatrical scene is a literal visual description of the afterlife.
- Keep the room-specific section concise enough that the event details do not get buried.
- The image headline and post hook should reinforce one another rather than introduce competing messages.
