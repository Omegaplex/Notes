# Tour of Hell — Root Context

> Routing context for the Tour of Hell notes repository. Year-specific event details belong in the appropriate year subfolder rather than at this root.

## Active project year

The current active Tour of Hell project is **2026**.

Before doing Tour of Hell work, read:

`Church/Events/Tour of Hell/2026/PROJECT-CONTEXT.md`

Then search recursively within:

`Church/Events/Tour of Hell/2026/`

for subject-specific notes related to the current request.

All year-specific Tour of Hell Markdown notes should be stored under the appropriate year folder. For current work, use the **2026** folder.

This root `PROJECT-CONTEXT.md` is intentionally retained as a stable entry point so project instructions and future chats can always find the active year context.

## Website context

Website implementation remains separate in:

`Omegaplex/tour-of-hell-site`

Use that repository for TourOfHell.cc, staff.tourofhell.cc, registration logic, Cloudflare Pages/Workers, D1, authentication, admin/staff pages, email handling, deployment, and website code/database structure.

## Context priority

When information conflicts, use this order:

1. The user's explicit instructions in the current conversation.
2. Current subject-specific notes in the active year folder.
3. The active year's `PROJECT-CONTEXT.md`.
4. Current website-repository context for website-specific matters.
5. Older project chats, legacy documents, brochures, prototypes, or historical notes.

A newer confirmed decision supersedes an older one.
